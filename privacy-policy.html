RoomPic 개인정보처리방침

시행일: 2026-08-31 (최종 개정: 2026-11-06)

RoomPic(이하 "서비스")은 이용자의 방 사진을 기반으로 마감재 변경 미리보기 이미지를 생성해 드리는 서비스입니다. 이 방침은 서비스 이용 과정에서 어떤 정보가 어떻게 처리되는지 설명합니다.

1. 수집하는 정보

  • 사진: 이용자가 촬영하거나 사진첩에서 선택해 업로드하는 방 사진.
  • 선택 정보: 이용자가 고른 적용 영역(벽/천장/바닥/창문)과 마감재 종류.
  • 위치 정보: "근처 시공업체 찾기" 기능을 사용할 때만, 기기의 GPS 위치 또는 직접 입력한 주소를 근처 업체를 검색하는 목적으로 카카오 지역 검색 API에 전달합니다. 기능을 사용하지 않으면 위치 권한으로 위치를 수집하지 않습니다. 지도 표시 시 OpenStreetMap 지도 서버에도 지도 요청과 IP 주소가 전달될 수 있으며, 서버·제공업체의 접속 로그가 남을 수 있습니다.
  • 기기 식별자: 서비스 이용 흐름을 파악하고, 무료로 이용할 수 있는 횟수(기기당 5회)를 계산하기 위해, 앱 설치 시 기기 안에서 무작위로 생성되는 식별자를 사용합니다. 이 식별자와 이용 횟수는 서비스 서버에 저장되며 생성 요청·이용 기록·처리시간과 연결될 수 있습니다. 이름·이메일 등 개인을 특정할 수 있는 정보와 연결되지 않으며, 다른 서비스와 공유하지 않습니다.
  • 이용 기록·성능 정보: 앱 실행·사진 업로드·생성·저장·공유 등의 이용 기록, 세션 ID, 운영체제, 생성 처리시간을 기기 식별자와 함께 수집해 이용 분석·성능 개선·오류 확인에 사용합니다. 접속 IP는 운영 로그에 남을 수 있습니다.
  • 신고 정보: AI 결과 신고를 선택할 때만 결과 축소 이미지(긴 변 최대 512px), 신고 사유, 결과 번호와 접수 번호를 수집합니다. 원본 사진은 신고에 별도로 첨부하지 않으며 광고 추적에 사용하지 않습니다.

서비스는 회원가입이나 로그인을 요구하지 않습니다. 일반 이용 과정에서 이름·이메일·전화번호 입력을 요구하지 않지만, 이용자가 문의 메일을 보내면 답변을 위해 메일 주소와 문의 내용을 처리합니다.

2. 정보의 이용 목적과 제3자 제공

업로드된 사진은 미리보기 이미지를 생성하기 위한 목적으로만 사용되며, 이 과정에서 이미지 생성 처리를 위해 OpenAI, L.L.C.("OpenAI")의 API로 전송됩니다. OpenAI로 전송된 사진은 OpenAI의 API 데이터 이용 정책에 따라 처리됩니다.

"근처 시공업체 찾기" 기능을 사용하면, 위치 정보(또는 입력한 주소)가 근처 업체를 검색하는 목적으로 카카오(Kakao)의 지역 검색 API로 전송됩니다. 사진·위치 정보는 해당 기능 제공에 사용되며 광고 추적에 사용하지 않습니다. 서비스 서버 운영에는 Render와 Neon을 사용합니다. 신고 자료는 안전성 검토를 위해 운영자가 확인하며 이미지 생성 API로 보내지 않습니다.

3. 보관 기간

생성용 임시 사진은 처리 후 삭제하거나, 30분이 지나면 서버의 10분 주기 청소 시 삭제합니다. 정상 가동 중에도 약 40분까지 남을 수 있고 서버 중단 시 더 늦어질 수 있습니다. 신고 자료는 접수 30일 후 삭제 대상이 되며 주기적 청소 또는 신고 접수·관리자 조회 시 삭제됩니다. 기기 식별자·무료 이용 횟수·이용 기록·처리시간·비용 관리 기록은 서비스 운영과 이용 한도 관리에 필요한 동안 보관하며 현재 고정된 자동 만료 기간은 설정되어 있지 않습니다. 삭제를 요청하면 확인 후 처리합니다. 서비스 제공업체의 접속 로그와 백업은 해당 제공업체의 보관 정책이 적용되며 실시간 삭제를 보장하지 않습니다.

"즐겨찾기"와 "최근 결과"는 기기 안에 저장됩니다. 단, 이용자가 결과 신고를 보내면 해당 결과의 축소본이 신고 자료로 서버에 저장됩니다.

4. 기기 접근 권한

  • 카메라: 방 사진을 촬영하기 위해 사용됩니다.
  • 사진첩: 기존 사진을 선택하거나, 생성된 결과 이미지를 저장하기 위해 사용됩니다.
  • 위치: "근처 시공업체 찾기" 기능에서 근처 업체를 검색하기 위해 사용됩니다. 이 권한을 허용하지 않아도 직접 주소를 입력해 같은 기능을 쓸 수 있습니다.

이 권한들은 해당 기능을 사용하는 시점에만 사용되며, 다른 목적으로 접근하지 않습니다.

5. 이용자의 권리

기기 안의 저장 결과는 앱에서 삭제할 수 있습니다. 서버 자료의 열람·정정·삭제는 ahssi@kakao.com으로 요청할 수 있습니다. 기기 관련 자료는 설정의 “데이터 열람·삭제 요청”에서 확인한 기기 ID를, 신고 자료는 접수 번호를 함께 보내 주세요. 운영자는 해당 자료와 요청 권한을 확인해 처리하고 결과를 안내합니다. 원본 사진은 별도로 문의 메일에 첨부하지 않아도 됩니다.
